# 文献速览的维护方法

每篇论文采用同一种阅读结构，保留可放大的原创速览图、短文字说明、原图索引、三个回忆问题及完整引用。

## 当前内容

- `li-2025-al-scn-baw.html`：Li等2025年Al(Sc)N BAW综述的全文导读样例。
- `../assets/notes/li-2025-baw-recall.svg`：矢量速览图。
- `../assets/notes/li-2025-baw-recall.png`：下载用图片。

“全文导读”表示卡片覆盖论文主线，不表示站点作者已精读全文。首页已有的领域参考文献，也不自动计入个人已读清单。

## 下一篇需要的输入

1. 论文PDF或可访问的全文链接。
2. 实际已读范围：全文、某节，或指定图表。
3. 若有个人笔记，保留自己的理解、疑问与阅读日期；缺失的内容不代填。

## 固定内容格式

1. **文献身份**：标题、作者、年份、类型、DOI；区分综述、实验工作、理论工作和预印本。
2. **核心问题**：一两句话写清论文在解释或解决什么。
3. **原创速览图**：3–5个概念、必要的结构或机制示意；不添加未经支持的曲线或数值。
4. **关键解释**：问题、方法/机制、证据、适用条件与局限；每项保留章节、页码或图号。
5. **原图索引**：选2–5张最能触发回忆的图，标明每张图回答的问题及原文位置。
6. **回忆问题**：三个开放问题，答案默认折叠，供先回忆后核对。
7. **来源**：完整引用和可访问的原文入口。复用原图时逐项核对图注、第三方来源及许可。
