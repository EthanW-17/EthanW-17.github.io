01 / P3F

周期性极化压电薄膜

Periodically Poled Piezoelectric Film

通过配置压电层的极化或晶体取向，使机电激励更好地匹配目标高阶声学模态。AlScN 与铌酸锂（LiNbO3）平台已有谐振器及滤波器实验报道。部分 AlScN 文献也使用 Periodically Polarized 的写法。[1][2]

极化与层叠设计高阶声学模态高频滤波原型
P3F：代表进展与关注问题
  1. 2024LiNbO3 · 滤波器实验

    双层 P3F 的 23.8 GHz 滤波器

    Cho 等利用 S2 Lamb 模态构建三阶梯形滤波器。50 Ω 测量下，插入损耗为 1.52 dB，3 dB 相对带宽为 19.4%。[2]

  2. 2025AlScN · 滤波器实验

    四层 AlScN 的约 17.4 GHz 滤波器

    Izhar 等在四层 P3F 中制备高频谐振器，并实现三元件与六元件滤波器，展示该结构在 AlScN 平台上的器件与电路实现。[3]

  3. 2026LiNbO3 · 滤波器实验

    四层 P3F 的约 50 GHz 滤波器

    Barrera 等采用四层 LiNbO3 与 S12 模态，制备并测量中心频率约 50.1 GHz 的滤波器；论文同时讨论层厚控制、寄生响应和滤波器频差设计。[4]

阅读关注点

层厚偏差如何影响模态纯度与带外抑制？高频布线的电磁寄生如何进入器件模型？这些问题在约 50 GHz 滤波器工作中已有直接讨论。[4]

延伸阅读：多层压电平台的通用声学框架，以及利用反向晶向双层结构补偿残余应力的研究。[8][9]

02 / BAW

压电 BAW 滤波器

Piezoelectric Bulk Acoustic Wave Filters

利用压电薄膜中的体声波谐振实现射频频率选择。这里主要关注 AlN / ScAlN 薄膜路线：FBAR 借助空气腔体隔离声能，SMR 借助声学反射层限制声能泄漏。材料、薄膜质量与电极设计共同影响耦合和损耗。[11]

FBAR / SMR薄膜与电极带宽与损耗
BAW：代表进展与关注问题
  1. 2025ScAlN · 单谐振器实验

    12.5 GHz ScAlN FBAR

    Cho 等使用 ScAlN 薄膜与 Pt 底电极实现 12.5 GHz 谐振器，并报告 Q 为 208、耦合系数 k² 为 9.5%，为高频薄膜与电极协同设计提供实验案例。[5]

  2. 2026ScAlN · 滤波器实验

    11.7 GHz FBAR 滤波器与损耗分析

    已发表的单层 ScAlN 梯形滤波器，在 50 Ω 测量下获得 4.0% 的 3 dB 相对带宽与 6.8 dB 最小插入损耗。论文分析材料、电极、频差与残余应力带来的高频化限制。[6]

  3. 2026ScAlN · 单谐振器实验

    62.6 GHz 固态装配谐振器

    Wang 等将 ScAlN / Pt 堆栈置于 SiO2 / Ta2O5 布拉格反射器上，实现三阶厚度伸缩模式的 SMR。该结果对应单个谐振器的实测响应。[7]

阅读关注点

提高工作频率时，怎样同时保持薄膜晶质、降低电极损耗并控制残余应力？从单个谐振器走向滤波电路，还需要考虑串并联谐振器频差、端口匹配与带宽。[6]

AlScN 与 ScAlN 均表示钪掺杂氮化铝，页面沿用各论文的写法；不同研究的 Q、耦合系数和滤波指标，应结合原文定义及测量条件阅读。

RECENT READING2026.09 · 预印本

近期公开探索还包括双层 LiNbO3 的厚度剪切泛音谐振器，用于研究亚 GHz / 低 GHz 频段的高 Q 模态。这是一项谐振器实验，当前公开版本为预印本。[10]

EXPERIMENT 001 / P3F

双层 P3F · 模态重叠

移动层界面，观察极化符号与模态应变如何相长或抵消。这是同质、自由表面薄膜的一维教学模型，不是器件仿真或实测结果。

实线：归一化应变 Sₙ；虚线：pSₙ（极化加权应变）。箭头沿厚度正方向或反方向；界面虚线随厚度比例移动。

静态空间分布 · 无自动动画
模型、公式与适用范围

固定总厚度 H，x = z/H，r = h₁/H。两层具有相同密度 ρ、弹性常数 c、介电常数及压电系数绝对值，只改变极化符号 p₁、p₂ ∈ {−1,+1}。理想粘合界面位移与应力连续；外表面无机械载荷，自由边界 ∂u/∂z = 0。忽略压电反作用，以未耦合声学本征模作为基底。

uₙ ∝ cos(nπx), Sₙ = sin(nπx), fₙ = n√(c/ρ)/(2H), n ≥ 1

应变已按峰值归一化；其整体符号任意。假定外电极提供均匀厚度电场 E，极化反转只令 e 变号，激励投影正比于 ∫ eESₙ dz。

I₁ = p₁[1 − cos(nπr)]/(nπ)
I₂ = p₂[cos(nπr) − (−1)ⁿ]/(nπ)
ηₙ = |∫₀¹ p(x)Sₙ dx|² / [(∫₀¹ p² dx)(∫₀¹ Sₙ² dx)] = 2(I₁ + I₂)²

ηₙ ∈ [0,1] 是归一化空间重叠指标，不是 k_eff²，也不是不同结构各自最大值归一化。I₁、I₂ 为带符号分层贡献。全局翻转两层极化只改变投影符号，不改变 ηₙ。等厚反向极化抑制奇数阶；偶数阶也并非全部增强，例如 n = 4 完全抵消。不等厚可解除部分对称性禁戒，也会削弱某些原本可激励的模态。

这里只以厚度比例表示不等厚，不等同于论文中所有 M≠N 结构。未包含异质声阻抗、各向异性、非均匀电场、电极质量、损耗、横向边缘或电声耦合引起的频移；实际 k_eff² 需材料张量、电边界与耦合求解或可靠谐振数据，本演示不提供其数值。
