NOTE 01 / START SMALL

先做一个可以运行的小版本

给想法一个最小的起点：一张草图、一个按钮，或者一个能回答问题的小实验。完成之后，再决定下一步。

NOTE 02 / MAKE IT VISIBLE

让抽象的东西变得可见

如果一个概念很难解释，试着画出来、调一调，或者做成可以操作的模型。反馈，往往比一段说明更直接。

NOTE 03 / LEAVE A TRACE

记录为什么，也记录下一步

不只保存最终结果，也记下当时的判断与待解的问题。给未来的自己留一点线索，下一次就能从这里继续。
