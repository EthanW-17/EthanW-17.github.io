# Ethan — 学术个人主页

面向导师、科研同行与潜在合作者的学术个人主页，部署于 GitHub Pages。采用米白、墨绿与青柠绿配色，兼顾桌面与手机显示。

## 内容与交互

- 首页展示 Ethan 的博士研究生身份，以研究方向与联系交流为主要入口。
- 研究方向：P3F 相关研究、压电 BAW 滤波器相关研究。
- 页面顺序：研究方向、关于、交互演示、联系。
- 联系入口链接至本人提供的 GitHub 账号。
- 原生 Canvas 点阵环，随指针轻微转动。
- 信号实验室：调整正弦波振幅和频率，并恢复初始参数。
- 轨道练习：调节几何动画速度、暂停与继续。
- 灵感备忘录：三条可替换的示例笔记。
- 手机导航、键盘操作、原生对话框和减少动态效果支持。

身份与两项研究方向来自本人确认。研究问题、个人贡献、进展与公开成果将在提供资料后补充；当前没有预设学校、导师、论文或性能指标。P3F 保留本人提供的缩写，未推测其全称或与 BAW 方向的具体关系。

信号、轨道和笔记是单独标注的网页交互示例，不代表 P3F 或 BAW 研究成果。联系方式仅链接到已提供的 GitHub 账号，没有预设邮箱。

## 本地查看

下载 `index.html`，直接用现代浏览器打开即可。页面不依赖外部脚本、字体或图片，也不需要安装包或运行构建命令。

## 修改内容

所有 HTML、CSS、JavaScript 与 SVG 图形都在 `index.html` 中：

- 搜索 `EDIT:`，找到配色、首页文案、研究方向和交互示例的位置。
- `:root` 中的 `--bg`、`--ink`、`--accent` 控制主要颜色。
- 修改 `hero-title`、`hero-description` 和 `about-section` 里的个人介绍。
- 在 `research-section` 的两项 `research-card` 中补充可公开的研究问题、个人贡献、进展和成果链接。
- 三个 `project-card` 属于交互演示；如要替换成研究相关可视化，应核实数据来源并保留恰当说明。
- 修改 `https://github.com/EthanW-17` 可更换 GitHub 联系入口。

## GitHub Pages

仓库： https://github.com/EthanW-17/EthanW-17.github.io

在仓库 Settings → Pages 中，将 Source 设置为 **Deploy from a branch**，选择 **main** 分支、**/(root)** 目录并保存。部署成功后，个人站点地址为：

https://ethanw-17.github.io/

`.nojekyll` 用于让 GitHub Pages 直接发布静态文件。

## 文件说明

- `index.html`：完整网站。
- `.nojekyll`：静态发布标记。
- `README.md`：本说明。

网站没有服务器端服务，不收集报名数据，也没有账号系统。浏览器中显示的波形属于交互示意，坐标为归一化坐标，不是测量数据；轨道为几何动画，不是天体物理仿真。
