# Ethan — 研究兴趣与文献笔记

面向导师、科研同行与潜在合作者的学术个人主页，部署于 GitHub Pages。以博士研究生的研究兴趣与公开文献学习为定位，采用米白、墨绿与青柠绿配色，兼顾桌面与手机显示。

## 内容与交互

- 首页展示 Ethan 的博士研究生身份，以阅读研究现状与联系交流为主要入口。
- 研究兴趣：周期性极化压电薄膜（P3F）、压电 BAW 滤波器。
- 两项领域概述均可展开阅读代表进展、研究问题与原始来源。
- 参考文献包含正式论文、开放作者稿与明确标注的预印本；另有一份官方技术资料用于基础结构说明。
- 页面顺序：研究兴趣与领域现状、关于、交互演示、联系。
- 联系入口链接至本人提供的 GitHub 账号。
- 原生 Canvas 点阵环，随指针轻微转动。
- 信号实验室：调整正弦波振幅和频率，并恢复初始参数。
- 轨道练习：调节几何动画速度、暂停与继续。
- 灵感备忘录：三条可替换的示例笔记。
- 手机导航、键盘操作、原生对话框和减少动态效果支持。

身份与两项研究兴趣来自本人确认。页面的全部研究内容均为公开文献中的领域现状，相关结果属于原论文作者，不是站点所有者的个人研究成果或进度。页面没有预设学校、导师或个人论文。

P3F 使用文献中的常见全称 **Periodically Poled Piezoelectric Film**，部分 AlScN 文献采用 **Periodically Polarized Piezoelectric Film**。P3F 板块包含 AlScN 和 LiNbO₃ 的相关声学平台；BAW 板块主要关注 AlN / ScAlN 的 FBAR 与 SMR 路线。

## 文献范围与更新

本次整理日期为 **2026-10-20**，选择 2023–2026 年的代表性原始研究，并区分单谐振器、滤波器、实测结果和预印本。引用序号与完整阅读链接均保存在 `index.html` 的 `references` 中，正文引用可直接打开原始来源。

- 2024 年双层 LiNbO₃ P3F 滤波器的指标使用原文 **50 Ω 测量**结果。
- 2025 年四层 AlScN P3F 工作按正式期刊年份列出，提供较早公开作者稿的入口。
- 约 50 GHz P3F 滤波器、11.7 GHz ScAlN FBAR 滤波器与 62.6 GHz SMR 均按已核实的 **2026 年正式卷期**列出；62.6 GHz 结果属于单谐振器。
- 2026 年 9 月双层 LiNbO₃ 厚度剪切泛音工作仍标为 **预印本**。
- 多层平台通用声学框架与残余应力补偿列为延伸阅读，未将已有研究误写为尚不存在的领域成果。

更新时应同时核实论文题名、发表状态、指标定义和测试条件，并修改页面整理日期。这是一份人工整理的文献快照，不自动抓取最新论文。

信号、轨道和笔记是单独标注的网页交互示例，不代表 P3F 或 BAW 研究成果。联系方式仅链接到已提供的 GitHub 账号，没有预设邮箱。

## 本地查看

下载 `index.html`，直接用现代浏览器打开即可。页面不依赖外部脚本、字体或图片，也不需要安装包或运行构建命令。

## 修改内容

所有 HTML、CSS、JavaScript 与 SVG 图形都在 `index.html` 中：

- 搜索 `EDIT:`，找到配色、首页文案、公开文献和交互示例的位置。
- `:root` 中的 `--bg`、`--ink`、`--accent` 控制主要颜色。
- 修改 `hero-title`、`hero-description` 和 `about-section` 里的个人介绍。
- 在 `research-section` 的两项 `research-card` 中更新领域概述、`paper-list` 代表进展及引用；避免把引用文献的结果改写成个人成果。
- `p3f-reading`、`baw-reading` 和 `references` 使用原生 `details` 折叠，关闭 JavaScript 后仍可阅读。
- 三个 `project-card` 属于交互演示；如要替换成研究相关可视化，应核实数据来源并保留恰当说明。
- 修改 `https://github.com/EthanW-17` 可更换 GitHub 联系入口。
